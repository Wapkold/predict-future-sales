# Прогноз продаж: Kaggle Predict Future Sales

Задача соревнования [Predict Future Sales](https://www.kaggle.com/competitions/competitive-data-science-predict-future-sales) (1С): по ежедневным продажам за январь 2013 – октябрь 2015 предсказать, сколько штук каждого товара продаст каждый магазин в ноябре 2015. Метрика — RMSE по месячным продажам, обрезанным в диапазон 0–20.

## Результат

Валидация по времени: модель учится на месяцах до сентября 2015 включительно и проверяется на октябре 2015 (месяц 33), то есть ровно так, как устроен настоящий тест — прогноз на следующий месяц.

| Модель | RMSE на октябре 2015 |
|---|---:|
| Скользящее среднее, 1 месяц | 1.136 |
| Скользящее среднее, 3 месяца | 1.021 |
| Скользящее среднее, 6 месяцев | 1.028 |
| **LightGBM** | **0.869** |

LightGBM снижает ошибку на **15%** относительно лучшего baseline (0.869 против 1.021). Ранняя остановка выбрала 82 итерации. Числа взяты из `metrics.json`.

## Как устроено

**Сетка.** Для каждого месяца строится декартово произведение «все магазины, работавшие в этом месяце × все товары, проданные в этом месяце», и пары без продаж получают ноль. Без этого модель видит только ненулевые продажи и систематически завышает прогноз, а в тесте большинство пар как раз нулевые.

**Очистка.** Отброшены выбросы по цене и количеству. Три магазина-дубликата (одинаковые названия в `shops.csv`, разные id: 0→57, 1→58, 11→10) сведены к тем id, которые есть в тесте.

**Признаки LightGBM:**
- лаги продаж пары магазин–товар за 1, 2, 3, 6 и 12 месяцев;
- лаги средних продаж по товару, магазину, категории и паре магазин+категория;
- скользящие среднее и стандартное отклонение за 3 месяца, тренд;
- возраст товара и пары магазин–товар (месяцев с первой продажи);
- средняя цена товара, категория и её тип, месяц года.

Первые 12 месяцев уходят на заполнение лага 12 и в обучение не попадают.

**Финальная модель** переобучается на всех месяцах до октября 2015 включительно с числом итераций `best_iteration × 1.05` и предсказывает ноябрь. Прогноз, как и целевая переменная, обрезается в 0–20.

## Запуск

```bash
pip install -r requirements.txt
kaggle competitions download -c competitive-data-science-predict-future-sales -p data
unzip data/competitive-data-science-predict-future-sales.zip -d data
python forecast.py --data data --out output
```

Для скачивания нужен [Kaggle API token](https://www.kaggle.com/docs/api) и принятые правила соревнования.

Результат в `output/`:

| Файл | Что внутри |
|---|---|
| `submission.csv` | прогноз LightGBM для отправки на Kaggle |
| `submission_baseline.csv` | прогноз скользящего среднего за 3 месяца |
| `metrics.json` | RMSE всех моделей на валидационном месяце |
| `feature_importance.csv` | важность признаков LightGBM (gain) |
